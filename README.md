# Women Safety Computer-Vision Project

Computer-vision and machine-learning project organized into data-cleaning, data-download, backend, and training/testing areas.

## Project layout

- `DataClean/`: data-cleaning work.
- `DataDownloading/`: data acquisition utilities and their local instructions.
- `backendcodes/`: backend code.
- `training&testing/`: model training and evaluation experiments.

Review the scripts and `requirements.txt` in the relevant component before setup. Dataset availability and model paths may depend on local files; do not commit private data or credentials.
